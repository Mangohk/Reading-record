# Reading Record (Cloud Edition)

A single-page web app for students to log books they have read, and for teachers to review those records.

Open `index.html` in a browser (requires Firebase config for cloud sync).

## Features

- **Student login** — name, class, and class number
- **Book logging** — title, author, genre, pages, finish date, rating, and review
- **Personal library** — bookshelf or list view, with reading stats and ranks
- **Teacher portal** — password-protected overview of all student records
- **Export** — download records as CSV (Excel-compatible)
- **Cloud storage** — Firebase Firestore sync across devices
